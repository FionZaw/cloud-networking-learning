
# Project 01: Cloud Network Monitoring & Troubleshooting Lab

## 1. Project Overview

This project explores how cloud networks are designed, monitored and troubleshot using AWS.

The objective is to understand cloud networking concepts through practical exercises and technical documentation.

## 2. Objectives

- Understand AWS networking fundamentals.
- Learn how Amazon VPC works.
- Understand public and private subnets.
- Explore routing and network connectivity.
- Understand AWS security groups.
- Learn basic network monitoring.
- Practise identifying and troubleshooting connectivity issues.

## 3. Technologies

- Amazon Web Services (AWS)
- Amazon VPC
- Amazon EC2
- AWS CloudWatch
- GitHub
- Python (future implementation)

## 4. Project Scope

Phase 1: Research and understand AWS networking.

Phase 2: Design a basic cloud network architecture.

Phase 3: Implement a practical AWS networking environment.

Phase 4: Explore monitoring and troubleshooting.

Phase 5: Document findings and lessons learned.
